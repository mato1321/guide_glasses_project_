# 人臉註冊工具

用瀏覽器上傳照片、標註人名，再讓眼鏡同步過去。

**不需要 `pip install` 任何東西**，只用 Python 標準函式庫。
也不需要 InsightFace 或任何模型 —— 特徵是眼鏡自己算的。

---

## 三步驟

### 1. 啟動

```bash
cd guide-glasses/tools && python face_enroll_server.py
```

它會印出兩個網址與一行設定：

```
人臉註冊伺服器已啟動
  照片資料夾  D:\...\guide-glasses\tools\face_photos
  本機開      http://127.0.0.1:8100
  手機／眼鏡  http://192.168.1.23:8100      <-- 用這個

眼鏡設定（寫進 guide-glasses/local.properties）：
  guideglasses.photoEndpoint=http://192.168.1.23:8100
```

### 2. 用瀏覽器上傳照片

手機或電腦開 `http://192.168.1.23:8100`（用它印出來的那個位址）。

- **姓名**：打進去的字就是眼鏡會唸出來的
- **照片**：可多選。手機點下去會**直接開相簿**
- 建議每人 3–5 張不同角度與光線的正面照

同一頁下方會列出已註冊的人，可以刪除。

> 💡 **眼鏡不在同一個 Wi-Fi 也可以**：接著 USB 跑
> `adb reverse tcp:8100 tcp:8100`，然後把 `photoEndpoint` 設成
> `http://127.0.0.1:8100`。眼鏡的 localhost 會被導到這台電腦。

### 3. 讓眼鏡同步

把上面那行 `guideglasses.photoEndpoint=...` 貼進 `guide-glasses/local.properties`，
重新建置安裝，然後對眼鏡說：

> **「同步人臉」**

眼鏡會把照片抓下來、用自己的模型算特徵、存進本地加密資料庫。
之後說「這是誰」就**完全離線可用** —— 這個工具關掉也沒關係。

---

## 為什麼同步照片而不是特徵

不同模型算出來的特徵在不同的向量空間。若這台機器用 InsightFace ResNet50、
眼鏡用 MobileFaceNet，直接把特徵搬過去**不會報錯**，維度甚至可能剛好相同，
但比對結果是隨機的 —— 系統會安靜地認不出任何人。

同步照片、讓眼鏡用自己的模型重算，特徵空間就永遠一致。
照片用完即棄，**不會存進眼鏡**。

---

## 同步完成時會聽到什麼

> 「同步完成，3 人，11 張照片」

如果有照片偵測不到人臉：

> 「同步完成，3 人，9 張照片，略過 2 張沒有偵測到人臉的」

如果**模型有問題**：

> 「同步完成，3 人，11 張照片。但同一個人的照片相似度只有 8 %，人臉模型可能不正確」

最後這句很重要。模型前處理不符時特徵會變成接近隨機的向量，
同一個人不同照片的相似度會塌到 0 附近 —— 但**不會有任何錯誤訊息**。
同步時剛好有多張同一人的照片可以互相比對，所以順手把這個靜默失敗變成聽得見的警告。

正常的模型下這個數字通常在 60% 以上，低於 35% 就會警告。

## 排錯

| 現象 | 原因 | 處理 |
|---|---|---|
| 手機開不了那個網址 | 不在同一個 Wi-Fi | 確認兩者同網段；公司／學校網路可能隔離裝置 |
| 眼鏡說「還沒設定註冊工具的位址」 | `photoEndpoint` 沒設或設錯地方 | 貼進 `local.properties` 後**一定要重新建置**（設定是編譯期注入的） |
| 眼鏡說「缺少人臉模型檔」 | `assets/` 裡沒有模型 | 見 [`../ai/ai-face/src/main/assets/README.md`](../ai/ai-face/src/main/assets/README.md) |
| 眼鏡說「註冊工具上還沒有任何人」 | 還沒上傳，或資料夾路徑不同 | 瀏覽器確認清單有人 |
| 某些照片被略過 | 沒偵測到臉、或一張照片裡有兩個人 | 註冊照片要只有本人、臉要夠大（>10% 畫面寬） |
| 同步失敗但舊資料還在 | 這是刻意的 | 全部失敗時**不清空資料庫** —— 保留舊資料比讓使用者突然誰都不認得好 |

## 檔案放哪

照片存在 `tools/face_photos/<姓名>/001.jpg`（已被 `.gitignore` 排除，不會進版控）。

要換位置：

```bash
python face_enroll_server.py --dir D:\my_photos --port 9000
```

---

## 安全性

這是**區網內的開發工具**，沒有認證機制。同一個 Wi-Fi 上的任何人都能讀寫。
不要放在公開網路上。

已做的防護：路徑穿越（`../`）會被擋、只接受圖片副檔名、單檔上限 10MB。

## 語音指令偵測率測試

眼鏡上沒有畫面也沒有鍵盤，測語音只能「人對著它講、看 logcat」。
`test_commands.ps1` 把那件事變成照著唸就好：

```powershell
cd guide-glasses\tools
pwsh .\test_commands.ps1
```

它會逐條提示要說什麼、收集偵測結果，最後列出**每一句的命中率**、
誤判成什麼、以及誤觸次數，並把逐輪明細寫成 CSV。

只測某幾條、每條多說幾次：

```powershell
pwsh .\test_commands.ps1 -Only "這是誰","唸給我聽" -Reps 5
```

全部跑完約 13 分鐘（14 句 × 3 次）。趕時間就 `-Reps 2`。

### 它量的是什麼

量的是**關鍵詞偵測**（常駐監聽，聽到指令直接做），不是語音辨識。
兩者是不同的路徑，log 也不同：

| | 關鍵詞偵測 | 語音辨識 |
|---|---|---|
| 什麼時候用 | 14 句固定指令 | 開放式輸入（要翻譯的整段話） |
| log | `WakeWord: 偵測到語音指令：「⋯」` | `OfflineAsr: 辨識完成：「⋯」` |

指令清單**直接從 `ai/ai-asr-offline/src/main/assets/kws/keywords.txt` 讀**，
不寫死在腳本裡 —— 寫死的清單一定會跟程式碼脫節。

> ⚠️ 要用 **pwsh 7**。Windows PowerShell 5.1 會把中文提示顯示成亂碼。
>
> ⚠️ 跑之前背景限制要先解除，否則測到一半 App 會被系統回收
> （腳本會先檢查，沒解除會直接擋下來）。見 [`../../docs/PROVISIONING.md`](../../docs/PROVISIONING.md)。

### 結果怎麼用

命中率低的句子，在 `keywords.txt` 補一行同義說法（拼音 ＋ `@漢字`），
**並且**在 `VoiceCommand.MAPPING` 加上對照 —— 只改一邊會安靜地沒反應。

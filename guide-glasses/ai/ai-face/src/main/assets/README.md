# 人臉特徵模型放這裡

本專案**不含模型權重**。`.tflite` 被 `.gitignore` 排除，而且各家模型有
各自的授權條款，不適合直接進版控。

## 需要放什麼

一個輸出人臉特徵向量的 TFLite 模型，檔名為：

```
mobilefacenet.tflite
```

## 規格要求

| 項目 | 要求 |
|---|---|
| 輸入尺寸 | 112 × 112（見 `TfLiteFaceEmbedder.INPUT_SIZE`） |
| 輸入格式 | RGB float32，正規化到 [-1, 1] |
| 輸出 | 一維特徵向量（維度由程式自動讀取，128 / 192 / 512 都可以） |

## 如果模型的前處理不同

`TfLiteFaceEmbedder.toInputBuffer()` 目前做的是 `(pixel - 127.5) / 127.5`。
若你的模型用 `[0, 1]` 或 ImageNet 標準化，**必須改這一段**。

前處理不符不會有任何錯誤訊息 —— 模型照樣輸出向量，只是那些向量沒有意義，
系統會安靜地認不出任何人。這是最難除錯的一種失敗，所以請務必確認。

## 沒有模型會怎樣

`TfLiteFaceEmbedder.isAvailable` 為 false，助理會播報
「人臉特徵模型不可用」—— 刻意不靜默失敗。
其他功能（OCR、相機、語音）不受影響。

## 換模型之後

已註冊的人臉特徵是用舊模型產生的，維度或特徵空間都可能不同。
`FaceMatcher` 會跳過維度不符的資料，但**維度剛好相同卻是不同模型**的情況
無法自動偵測 —— 換模型後請重新註冊所有人臉。
